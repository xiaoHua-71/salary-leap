# 下一步计划

## 已完成

### 第 1 步：接通 langchain4j ✅

- 依赖、分模块配置、AiServices + ChatModel 注入、生成关卡测试接口
- 详见 [04-langchain4j接入.md](04-langchain4j接入.md)

### 第 2 步：生成关卡并入库 ✅

- `POST /api/level/generate`：AI 生成关卡，存 `Level` 表，返回不含答案的 `LevelVO`
- 详见 [05-生成关卡模块.md](05-生成关卡模块.md)

### 第 3 步：作答 + 生成报告 + 更新薪资 ✅

- `POST /api/level/submit`：提交 levelId + 选项，AI 出报告，更新 `User.salary`，保存 `UserLevel`
- 详见 [08-作答报告模块.md](08-作答报告模块.md)

### 第 4 步：排行榜 ✅

- `GET /api/rank`：按 `User.salary` 降序返回用户排名
- 详见 [09-排行榜模块.md](09-排行榜模块.md)

## MVP 已完成 🎉

四个步骤全部跑通，MVP 闭环：注册 → 生成关卡 → 作答生成报告 → 更新薪资 → 排行榜。

## 后续完善方向

- 生成关卡改为从登录用户取薪资（目前是前端传 salary 参数）
- 报告 / 流式输出（`langchain4j-reactor` 已引入）
- 关卡按方向 / 难度等扩展
