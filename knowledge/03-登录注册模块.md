# 登录注册模块

## 功能

- 注册：支持密码注册 / 邮箱验证码注册（策略模式）
- 登录：账号密码校验，写入 session
- 获取当前用户、注销

## 已解决的问题

### 1. 登录序列化失败

- 现象：登录报 `NotSerializableException: com.xiaohua.model.entity.User`
- 原因：`userLogin` 把 `User` 存入 session，项目用了 Redis session（JDK 序列化），而 `User` 没实现 `Serializable`
- 修复：`User implements Serializable` + `private static final long serialVersionUID = 1L`

### 2. 主键类型统一

- `User.id` 由 `String` 改为 `Long`（与数据库 BIGINT 自增、与 `Level`/`UserLevel`/`LoginUserVO` 一致）
- 连锁改动：
  - `UserVO.id`
  - `AvatarUtils.getDefaultAvatarByUserId` 参数类型
  - `UserService` / `UserServiceImpl` 的 `userRegister` 返回类型、`updateUserSalary` 参数
  - `RegisterStrategy` 及两个实现（`PasswordRegisterStrategy`、`EmailRegisterStrategy`）的 `register` 返回类型
  - `UserController` 注册接口返回类型

### 3. 请求字段命名

- `UserLoginRequest` 的 `Username` / `Password` 改为小写 `username` / `password`

### 4. 密码加密改为 BCrypt

- MD5 + 固定盐 → `BCryptPasswordEncoder`，详见 [07-密码加密BCrypt改造.md](07-密码加密BCrypt改造.md)
