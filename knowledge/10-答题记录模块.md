# 答题记录模块

## 数据流

1. Controller 取当前登录用户
2. 按 `userId` 查 `UserLevel` 表（逻辑删除自动过滤）
3. 统计概览：`totalCount` = 记录数，`avgScore` = 平均分，`totalSalaryChange` = 累计 salaryChange，`currentSalary` 查 `User` 表
4. 历史列表：按 `createTime` 倒序，批量查 `Level` 表补关卡名，组装 `UserLevelVO`

## 文件清单

| 文件 | 作用 |
|------|------|
| model/vo/AnswerSummaryVO.java | 统计概览视图 |
| model/vo/UserLevelVO.java | 历史记录条目视图 |
| service/UserLevelService.java | 加 `getAnswerSummary` / `listUserLevels` |
| service/impl/UserLevelServiceImpl.java | 实现统计 + 列表查询 |
| controller/RecordController.java | `GET /record/summary`、`/record/list` |

## 关键点

- 统计概览的 `currentSalary` 直接取 `User.salary`；`totalSalaryChange` 为 `UserLevel.salaryChange` 累计求和
- 历史列表通过 `levelMapper.selectBatchIds` 批量补关卡名，避免 N+1 查询
- `UserLevelServiceImpl` 注入 `LevelMapper`/`UserMapper`（而不是 Service），避免与 `LevelServiceImpl` 循环依赖
- 未登录返回 `code = 40100`，与业务异常（`50000`）分开处理

## 接口

- `GET /api/record/summary`（需登录）→ `AnswerSummaryVO`（totalCount / avgScore / currentSalary / totalSalaryChange）
- `GET /api/record/list`（需登录）→ `List<UserLevelVO>`（id / levelId / levelName / score / salaryChange / createTime）
