# 排行榜模块

## 数据流

1. Controller 无参调用 `userService.getRankList()`
2. Service 按 `salary` 降序查询所有用户（MyBatis-Plus 自动过滤逻辑删除）
3. 遍历组装 `RankVO`，`rank` 从 1 开始递增

## 文件清单

| 文件 | 作用 |
|------|------|
| model/vo/RankVO.java | 排行榜用户视图（rank + 用户信息 + salary） |
| service/UserService.java | 加 `getRankList` |
| service/impl/UserServiceImpl.java | 按薪资降序查询并组装 |
| controller/RankController.java | `GET /rank` 接口 |

## 关键点

- 排序：`QueryWrapper.orderByDesc("salary")`，逻辑删除由 MyBatis-Plus 自动拼接 `is_delete = 0`
- `rank` 从 1 开始，由列表下标 + 1 得到
- `id` 为 Long，序列化时全局转字符串（防 JS 精度丢失）

## 接口

`GET /api/rank` → 返回 `List<RankVO>`
