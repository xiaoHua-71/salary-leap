# 作答报告模块

## 数据流

1. Controller 接收 levelId + 用户选中的选项
2. 从 Level 表取关卡，反序列化 `options`，提取正确选项（`trueAnswer = true`）
3. 取当前登录用户及其薪资
4. 调 AI（生成报告提示词）出报告
5. 计算新薪资 `newSalary = max(0, 当前薪资 + salaryChange)`，更新 `User.salary`
6. 保存 `UserLevel` 作答记录

## 文件清单

| 文件 | 作用 |
|------|------|
| model/ai/ReportResult.java | AI 生成的报告对象 |

| constant/AiPrompt.java | `GENERATE_REPORT_SYSTEM` 报告提示词 |
| config/AiConfig.java | 注册 `reportAiService` bean |
| service/LevelService.java | 加 `submitLevel` |
| service/impl/LevelServiceImpl.java | 实现作答逻辑 |
| service/impl/UserLevelServiceImpl.java | 改为 implements `UserLevelService`（注入需要） |
| controller/LevelController.java | 加 `/level/submit` 接口 |

## 关键点

- **正确选项来源**：`Level.options` 里存的是含 `trueAnswer` 的完整选项，作答时反序列化并按 `trueAnswer = true` 过滤得到正确答案列表
- **薪资更新**：调用 `userService.updateUserSalary(userId, salaryChange)`，内部已处理「薪资不为负」
- **salaryChange 符号**：正数加薪，负数减薪

## 接口

`POST /api/level/submit`（需登录）

请求体：

```json
{
  "levelId": "5",
  "userOptions": ["Vue 框架", "NPM 包管理器"]
}
```

响应 `data` 为 `ReportVO`：score / comment / salaryChange / suggest / reason / trueOptions / standardAnswer / newSalary
