# 项目概览

## 项目简介

salary-leap 是一个「程序员闯关加薪」游戏：用户注册后初始薪资 10k，通过闯关答题来加薪或降薪，最终按薪资生成排行榜。

## 技术栈

- Spring Boot 3.5.5 + Java 21
- MyBatis-Plus 3.5.13（ORM）
- MySQL + Redis
- Spring Session Redis（分布式 session）
- LangChain4j 1.4.0-beta10（接入阿里云百炼 / 通义千问）
- knife4j / springdoc（接口文档）

## 核心数据模型

| 表 | 实体 | 作用 |
|----|------|------|
| user | User | 用户，含 salary（当前薪资） |
| level | Level | 一道关卡（需求描述 + options JSON + 难度 + 目标薪资） |
| user_level | UserLevel | 某用户某关卡的作答记录（分数、评价、薪资变化、投递建议等） |

## 整体流程（闯关闭环）

1. 注册 → 初始薪资 10k
2. 登录
3. 生成关卡（AI）：根据当前薪资 → 生成一道题
4. 作答 → 生成报告（AI）：评分 + 评价 + 调薪 + 投递建议 + 正确选项 + 解析
5. 更新 User.salary
6. 排行榜：按薪资降序

## 提示词

AI 提示词放在 `prompt/角色提示词.md`，包含两套：

- 生成关卡提示词
- 生成结果报告提示词
