# 环境准备

## JDK

- 项目要求 Java 21（pom.xml 声明 `<java.version>21</java.version>`）
- 本机默认 `JAVA_HOME` 指向 JDK 11，直接编译会报「不支持发行版 21」
- 编译 / 启动需用 JDK 21：`E:/Java/jdk-21.0.5`

```bash
JAVA_HOME="E:/Java/jdk-21.0.5" PATH="E:/Java/jdk-21.0.5/bin:$PATH" mvn spring-boot:run
```

## 数据库与缓存

- MySQL：`localhost:3306/salary_leap`（root/root）
- Redis：`localhost:6379`

## 阿里云百炼 API Key（跑通 AI 的前提）

1. 打开 `bailian.console.aliyun.com`（登录阿里云账号，需实名认证）
2. 开通百炼大模型服务（新用户通常有免费额度）
3. 左侧菜单 **API-KEY** → 创建 API Key
4. 复制 `sk-` 开头的 key，填入 `application.yml` 的 `chat-model.api-key`
