# 生成关卡模块

## 数据流

1. Controller 接收 salary
2. Service 调 `LevelAiService.generateLevel(salary)` 得到 `LevelResult`（含选项 + 答案）
3. 选项序列化成 JSON 存入 `Level.options`
4. 返回 `LevelVO`（选项只含名称，不含答案）

## 文件清单

| 文件 | 作用 |
|------|------|
| model/ai/LevelOption.java | 选项 POJO（optionName + trueAnswer） |
| model/ai/LevelResult.java | AI 生成的关卡对象 |
| constant/AiPrompt.java | 生成关卡系统提示词 |
| service/ai/LevelAiService.java | AiServices 接口 |
| config/AiConfig.java | 构建 AiServices bean |
| model/vo/LevelVO.java | 返回前端的关卡（不含答案） |
| service/LevelService.java | 加 `generateLevel` |
| service/impl/LevelServiceImpl.java | 实现入库 |
| controller/LevelController.java | 接口入口 |

## 核心业务点：答案不能泄露

- 存库：`objectMapper.writeValueAsString(result.getOptions())` 把含 `trueAnswer` 的完整选项存进 `Level.options`
- 返回：`result.getOptions().stream().map(LevelOption::getOptionName)` 只给选项名，不给答案

## 接口

`POST /api/level/generate?salary=10000` → 返回 `LevelVO`
