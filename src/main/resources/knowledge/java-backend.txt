Java 后端开发

Redis 缓存穿透：查询一个根本不存在的 key，缓存和数据库都没有，请求会直接穿透缓存打到数据库。常见解法是用布隆过滤器提前拦截，或者把空值也缓存一小段时间。

Redis 缓存击穿：某个热点 key 在过期的一瞬间，大量并发请求同时打到数据库。解法可以用互斥锁只让一个线程去回源、其余等待，或者给热点 key 设置逻辑过期。

Redis 缓存雪崩：大量 key 在同一时间过期，或者 Redis 本身宕机，导致所有请求都打到数据库。解法是给 key 设置随机过期时间、做多级缓存、加限流降级。

消息队列的核心作用：削峰填谷、解耦、异步。常用中间件有 RocketMQ、Kafka、RabbitMQ。Kafka 吞吐高适合日志和埋点，RocketMQ 支持事务消息适合金融场景。

分布式事务：一个业务跨多个服务或数据库时，要保证数据一致性。理论基础是 CAP 和 BASE。常见方案有 2PC、TCC 补偿、本地消息表、Seata 的 AT 模式。

高并发缓存：应对海量请求以减轻数据库压力并提升系统响应速度。理论基础是缓存穿透、缓存雪崩、缓存击穿。常见方案有 Redis 缓存、多级缓存、布隆过滤器、热点数据本地缓存。
