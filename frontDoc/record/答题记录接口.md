# 答题记录接口

## 通用约定

- Base URL：`http://localhost:8101/api`
- 统一响应结构：`{ "code": 0, "data": {}, "message": "ok" }`（`code = 0` 表示成功）
- 所有 `Long` 类型 id 序列化后为**字符串**（防 JS 精度丢失）
- 以下接口均**需登录**，未登录返回 `code = 40100`

---

## 1. 获取答题统计概览

返回当前登录用户的总挑战次数、平均分数、当前薪资、薪资变化。

- **方法**：`GET /record/summary`
- **需登录**：是

### 响应

`data` 为统计概览。

```json
{
  "code": 0,
  "data": {
    "totalCount": 12,
    "avgScore": 78.5,
    "currentSalary": 25000,
    "totalSalaryChange": 15000
  },
  "message": "ok"
}
```

### 字段说明（AnswerSummaryVO）

| 字段 | 类型 | 说明 |
|------|------|------|
| totalCount | int | 总挑战次数 |
| avgScore | number | 平均分数（保留 1 位小数） |
| currentSalary | int | 当前薪资（元/月） |
| totalSalaryChange | int | 薪资变化（累计，正数加薪负数减薪） |

---

## 2. 获取历史答题记录

返回当前登录用户的历史答题记录列表，按作答时间倒序。

- **方法**：`GET /record/list`
- **需登录**：是

### 响应

`data` 为历史记录列表（数组，按作答时间倒序）。

```json
{
  "code": 0,
  "data": [
    {
      "id": "8",
      "levelId": "5",
      "levelName": "开发一个图书管理系统",
      "score": 80,
      "salaryChange": -2000,
      "createTime": "2026-09-01T10:30:00"
    },
    {
      "id": "7",
      "levelId": "3",
      "levelName": "用户登录接口安全加固与性能优化",
      "score": 90,
      "salaryChange": 3000,
      "createTime": "2026-08-31T15:20:00"
    }
  ],
  "message": "ok"
}
```

### 字段说明（UserLevelVO）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 记录 id |
| levelId | string | 关卡 id |
| levelName | string | 关卡名称 |
| score | int | 作答分数（满分 100） |
| salaryChange | int | 薪资变化（正数加薪，负数减薪） |
| createTime | string | 作答时间（ISO 格式） |

---

## 使用建议

- 个人中心 / 历史记录页：先调 `/record/summary` 渲染顶部统计卡片，再调 `/record/list` 渲染记录列表。
- 未登录时两个接口均返回 `code = 40100`，前端可据此跳转登录页。
