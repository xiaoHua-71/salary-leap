# salary-leap 前端接口文档

## 基本信息

- **Base URL**：`http://localhost:8101/api`
- **请求体**：`application/json; charset=utf-8`
- **登录态**：基于 Session + Cookie，登录后 Cookie 随请求自动携带，**前端无需手动存 token**
- **统一响应结构**：

```json
{
  "code": 0,
  "data": {},
  "message": "ok"
}
```

| 字段    | 类型   | 说明                          |
| ------- | ------ | ----------------------------- |
| code    | int    | 0 = 成功，非 0 = 失败         |
| data    | object | 业务数据（失败时为 null）      |
| message | string | 提示信息（失败时为具体原因）  |

## 重要约定

1. **id 是字符串**：所有 `Long` 类型 id（用户 id、关卡 id）序列化后为**字符串**（如 `"1"`），防 JS 精度丢失，前端直接当字符串用。
2. **登录态**：需登录的接口未登录时返回 `code = 40100`。

## 错误码

| code  | 含义           | 说明                              |
| ----- | -------------- | --------------------------------- |
| 0     | 成功           |                                   |
| 40000 | 请求参数错误   | 业务校验失败，message 为具体原因  |
| 40100 | 未登录         | 需登录接口未登录时返回            |
| 40101 | 无权限         |                                   |
| 40300 | 禁止访问       |                                   |
| 40400 | 数据不存在     |                                   |
| 50000 | 系统内部异常   |                                   |
| 50001 | 操作失败       |                                   |

## 接口总览

### 一、登录注册模块（login）

| 接口             | 方法 | 路径             | 需登录 |
| ---------------- | ---- | ---------------- | ------ |
| 用户注册         | POST | `/user/register` | 否     |
| 发送邮箱验证码   | POST | `/user/sendCode` | 否     |
| 用户登录         | POST | `/user/login`    | 否     |
| 获取当前登录用户 | GET  | `/user/current`  | 是     |
| 用户注销         | POST | `/user/logout`   | 是     |

### 二、关卡模块（level）

| 接口     | 方法 | 路径             | 需登录 |
| -------- | ---- | ---------------- | ------ |
| 生成关卡 | POST | `/level/generate` | 否     |
| 提交作答 | POST | `/level/submit`   | 是     |

### 三、排行榜模块（rank）

| 接口     | 方法 | 路径    | 需登录 |
| -------- | ---- | ------- | ------ |
| 排行榜   | GET  | `/rank` | 否     |

### 四、答题记录模块（record）

| 接口         | 方法 | 路径              | 需登录 |
| ------------ | ---- | ----------------- | ------ |
| 答题统计概览 | GET  | `/record/summary` | 是     |
| 历史答题记录 | GET  | `/record/list`    | 是     |
