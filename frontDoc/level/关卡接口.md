# 关卡接口

## 通用约定

- Base URL：`http://localhost:8101/api`
- 统一响应结构：`{ "code": 0, "data": {}, "message": "ok" }`（`code = 0` 表示成功）
- 所有 `Long` 类型 id 序列化后为**字符串**（防 JS 精度丢失）

---

## 1. 生成关卡

由 AI 生成一道闯关题目（选项不含答案）。**出题方向取自登录用户的学习方向标签**；未登录时用请求参数。

- **方法**：`POST /level/generate`

### 请求参数（query）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| salary | int | 否 | 当前薪资（默认 10000）。**登录后此参数被忽略**，改用用户当前薪资 |
| direction | string | 否 | 出题方向。**登录后此参数被忽略**，改用用户的 `direction` 标签 |

> 前端建议：登录后直接 `POST /level/generate` 即可，方向和薪资都从用户信息里取；未登录（游客试玩）才需要显式传 `salary` / `direction`。

### 请求示例

```
POST /level/generate
POST /level/generate?salary=10000&direction=Java后端开发
```

### 响应

`data` 为关卡信息。

```json
{
  "code": 0,
  "data": {
    "id": "5",
    "levelName": "开发一个图书管理系统",
    "levelDesc": "我们正在开发一个在线书店管理系统，旨在为用户提供便捷的购书体验……",
    "options": [
      "Vue 框架",
      "Zookeeper 分布式协调工具",
      "NPM 包管理器"
    ],
    "difficulty": "简单",
    "targetSalary": 10000,
    "source": "AI"
  },
  "message": "ok"
}
```

### 关卡字段说明（LevelVO）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 关卡 id |
| levelName | string | 关卡名称 |
| levelDesc | string | 需求描述 |
| options | string[] | 选项名称列表（不含答案） |
| difficulty | string | 难度：`简单` / `中等` / `困难` |
| targetSalary | int | 目标薪资 |
| source | string | 题目来源：`AI`（AI 生成）/ `PRESET`（AI 不可用时的预设题库兜底） |

> **降级说明**：当 AI 服务不可用时，后端会自动降级，返回**预设题库**里的题目（`source = "PRESET"`），而不是报错。前端可据此做提示（如「当前为系统预置题」），也可忽略、正常展示。

---

## 2. 提交作答（生成报告）

用户针对某关卡作答后，提交选中的选项，后端调用 AI 生成闯关报告并更新用户薪资。

- **方法**：`POST /level/submit`
- **需登录**：是（未登录返回 `code = 40100`）

### 请求参数（body）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| levelId | string | 是 | 关卡 id（生成关卡接口返回） |
| userOptions | string[] | 是 | 用户选中的选项名称列表 |

### 请求示例

```json
{
  "levelId": "5",
  "userOptions": ["Vue 框架", "NPM 包管理器"]
}
```

### 响应

`data` 为闯关报告。

```json
{
  "code": 0,
  "data": {
    "levelId": "5",
    "score": 80,
    "comment": "建议涨薪",
    "salaryChange": -2000,
    "suggest": "建议投递鱼皮公司",
    "reason": "答的不太好",
    "trueOptions": ["Vue 框架", "NPM 包管理器"],
    "standardAnswer": "……一段 Markdown 文本",
    "newSalary": 8000
  },
  "message": "ok"
}
```

### 报告字段说明（ReportVO）

| 字段 | 类型 | 说明 |
|------|------|------|
| levelId | string | 关卡 id |
| score | int | 作答分数（满分 100） |
| comment | string | 评价 |
| salaryChange | int | 薪资调整（正数加薪，负数减薪） |
| suggest | string | 投递公司建议 |
| reason | string | 评分原因 |
| trueOptions | string[] | 本关卡正确选项 |
| standardAnswer | string | 标准答案解析（Markdown） |
| newSalary | int | 更新后的薪资 |
