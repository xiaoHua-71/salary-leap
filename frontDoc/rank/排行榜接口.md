# 排行榜接口

## 通用约定

- Base URL：`http://localhost:8101/api`
- 统一响应结构：`{ "code": 0, "data": {}, "message": "ok" }`（`code = 0` 表示成功）
- 所有 `Long` 类型 id 序列化后为**字符串**（防 JS 精度丢失）

---

## 1. 获取排行榜

按当前薪资降序返回所有用户。

- **方法**：`GET /rank`

### 响应

`data` 为排行榜列表（数组），排名从 1 开始。

```json
{
  "code": 0,
  "data": [
    {
      "rank": 1,
      "id": "3",
      "username": "alice",
      "nickname": "Alice",
      "avatar": "https://img.icons8.com/color/96/000000/user-female-circle--v1.png",
      "salary": 25000
    },
    {
      "rank": 2,
      "id": "5",
      "username": "bob",
      "nickname": "Bob",
      "avatar": "https://img.icons8.com/color/96/000000/user-male-circle--v1.png",
      "salary": 12000
    }
  ],
  "message": "ok"
}
```

### 字段说明（RankVO）

| 字段 | 类型 | 说明 |
|------|------|------|
| rank | int | 排名（从 1 开始） |
| id | string | 用户 id |
| username | string | 用户名 |
| nickname | string | 昵称 |
| avatar | string | 头像 URL |
| salary | int | 当前薪资 |
