# 登录注册接口

## 通用约定

- Base URL：`http://localhost:8101/api`
- 请求体均为 `application/json`
- 登录后通过 Cookie / Session 保持登录态

### 统一响应结构

```json
{
  "code": 0,
  "data": {},
  "message": "ok"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 = 成功，非 0 = 失败 |
| data | object | 业务数据（失败时为 null） |
| message | string | 提示信息 |

### 状态码

| code | 含义 |
|------|------|
| 0 | 成功 |
| 40000 | 请求参数错误 |
| 40100 | 未登录 |
| 40101 | 无权限 |
| 40300 | 禁止访问 |
| 40400 | 数据不存在 |
| 50000 | 系统内部异常 |
| 50001 | 操作失败 |

### 重要约定：id 为字符串

所有 `Long` 类型的 id 字段（如用户 id），后端序列化后是**字符串**（例如 `"1"` 而不是 `1`），
目的是防止 JavaScript 大整数精度丢失。前端无需做数字运算，直接当字符串使用即可。

## 1. 用户注册

- **方法**：`POST /user/register`

### 请求参数（body）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 用户名（>=4 位，不含特殊字符） |
| password | string | 是 | 密码（>=8 位） |
| checkPassword | string | 是 | 确认密码（需与 password 一致） |
| nickname | string | 否 | 昵称 |
| email | string | 条件 | 邮箱（邮箱注册时必填） |
| code | string | 条件 | 邮箱验证码（邮箱注册时必填） |
| registerType | string | 否 | 注册方式：`password`（默认）/ `email` |

### 请求示例（密码注册）

```json
{
  "username": "xiaohua",
  "password": "12345678",
  "checkPassword": "12345678",
  "nickname": "小花",
  "registerType": "password"
}
```

### 请求示例（邮箱注册）

```json
{
  "email": "test@qq.com",
  "code": "123456",
  "password": "12345678",
  "registerType": "email"
}
```

### 响应

`data` 为新用户 id（字符串）。

```json
{
  "code": 0,
  "data": "3",
  "message": "ok"
}
```

## 2. 发送邮箱验证码

- **方法**：`POST /user/sendCode`

### 请求参数（body）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| email | string | 是 | 接收验证码的邮箱 |

### 请求示例

```json
{
  "email": "test@qq.com"
}
```

### 响应

```json
{
  "code": 0,
  "data": true,
  "message": "ok"
}
```

## 3. 用户登录

- **方法**：`POST /user/login`

### 请求参数（body）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |

### 请求示例

```json
{
  "username": "xiaohua",
  "password": "12345678"
}
```

### 响应

`data` 为用户信息（脱敏，不含密码）。

```json
{
  "code": 0,
  "data": {
    "id": "1",
    "username": "xiaohua",
    "nickname": "小花",
    "avatar": "https://img.icons8.com/color/96/000000/user-male-circle--v1.png",
    "userRole": "user",
    "salary": 10000,
    "createTime": "2026-08-26T10:30:00"
  },
  "message": "ok"
}
```

### 用户信息字段说明（UserVO）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 用户 id |
| username | string | 用户名 |
| nickname | string | 昵称 |
| avatar | string | 头像 URL |
| userRole | string | 角色：`user` / `admin` |
| salary | int | 当前薪资（元/月） |
| createTime | string | 创建时间（ISO 格式） |

---

## 4. 获取当前登录用户

- **方法**：`GET /user/current`

### 请求参数

无（依赖登录态 Cookie / Session）。

### 响应

同「用户登录」响应中的 `data` 结构。

```json
{
  "code": 0,
  "data": {
    "id": "1",
    "username": "xiaohua",
    "nickname": "小花",
    "avatar": "https://...",
    "userRole": "user",
    "salary": 10000,
    "createTime": "2026-08-26T10:30:00"
  },
  "message": "ok"
}
```

> 未登录时返回 `code = 40100`。
