# 前端接口文档

## 基本信息

- 项目：salary-leap
- 环境：dev
- Base URL：`http://localhost:8101/api`
- 请求方式：POST / GET（均为 JSON，`Content-Type: application/json; charset=utf-8`）
- 登录态：基于 Session + Cookie（无需前端保存 token，Cookie 随请求自动携带）

## 统一响应格式

```json
{
  "code": 0,        // 状态码，0 表示成功
  "data": null,     // 数据
  "message": "ok"   // 提示信息
}
```

## 错误码

| code  | 含义             | 说明                             |
| ----- | ---------------- | -------------------------------- |
| 0     | 成功             |                                  |
| 40000 | 参数错误         | 业务校验失败，`message` 为具体原因 |
| 40100 | 未登录           | 需要登录的接口未登录时返回        |
| 40101 | 无权限           |                                  |
| 40300 | 禁止访问         |                                  |
| 40400 | 请求数据不存在   |                                  |
| 50000 | 系统内部异常     |                                  |
| 50001 | 操作失败         |                                  |

> 注意：注册/登录/当前用户/注销等接口，业务校验失败时统一返回 `code=40000`，`message` 为具体原因（如"用户名过短""两次输入的密码不一致"）。

## 接口索引

| 接口                    | 方法 | 路径              | 是否需登录 |
| ----------------------- | ---- | ----------------- | ---------- |
| 注册（密码 / 邮箱）     | POST | `/user/register`  | 否         |
| 发送邮箱注册验证码      | POST | `/user/sendCode`  | 否         |
| 登录                    | POST | `/user/login`     | 否         |
| 获取当前登录用户        | GET  | `/user/current`   | 是         |
| 注销                    | POST | `/user/logout`    | 是         |

详见 [用户接口.md](用户接口.md)。
